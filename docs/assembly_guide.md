# 🔧 组装指南 —— AI网络安全管家

## 第一步：焊接 OLED 排针（如果需要）

大部分 OLED 模块买来不带排针，需要自己焊接：

1. 将 4 根排针插入 OLED 模块的 GND/VCC/SCL/SDA 孔
2. 用烙铁焊接（如果没有烙铁，可以让淘宝卖家帮你焊好，加 ¥2-5）
3. 或者买「已焊排针」版本的 OLED 模块

## 第二步：接线 —— ESP32 ↔ OLED

```
OLED 屏         ESP32 开发板
┌─────┐         ┌──────────┐
│ GND │────────▶│   GND    │  黑/棕色线
│ VCC │────────▶│   3.3V   │  红色线
│ SCL │────────▶│   D22    │  黄色线 (I2C Clock)
│ SDA │────────▶│   D21    │  绿色线 (I2C Data)
└─────┘         └──────────┘
```

> ⚠️ **重要**：VCC 必须接 **3.3V**，不要接 5V！OLED 是 3.3V 器件，接 5V 会烧坏！

**ESP32 引脚参考图：**
```
         ┌──────────────────┐
  EN  ←─┤○                 ○├─→  D23
  D36 ←─┤○                 ○├─→  D22 (SCL)
  D39 ←─┤○                 ○├─→  D1  (TX)
  D34 ←─┤○     ESP32       ○├─→  D3  (RX)
  D35 ←─┤○   DEVKIT V1     ○├─→  D21 (SDA)
  D32 ←─┤○                 ○├─→  D19
  D33 ←─┤○                 ○├─→  D18
  D25 ←─┤○                 ○├─→  D5
  D26 ←─┤○                 ○├─→  D17
  D27 ←─┤○                 ○├─→  D16
  D14 ←─┤○                 ○├─→  D4
  D12 ←─┤○                 ○├─→  D0
  D13 ←─┤○                 ○├─→  D2
  GND ←─┤○                 ○├─→  D15
  VIN ←─┤○                 ○├─→  GND
         │  ██  USB  ██  │
         └──────┬┬────────┘
                └┘
```

## 第六步：固定到外壳

### 无外壳方案（零成本）
用双面胶把 ESP32 和 OLED 粘在一起，立在显示器旁边。

### 3D 打印外壳方案
1. 下载 `enclosure/security_guardian_case.stl`
2. 上传到淘宝 3D 打印店铺（搜索 "3D打印 光固化 SLA"）
3. 选择白色树脂材质，约 ¥15-30
4. 到货后把 ESP32 + OLED 卡进去

## 第七步：烧录固件

### 7.1 安装 Arduino IDE
1. 下载 Arduino IDE: https://www.arduino.cc/en/software
2. 安装后打开

### 7.2 安装 ESP32 支持
1. 文件 → 首选项 → 附加开发板管理器网址，填入：
   ```
   https://espressif.github.io/arduino-esp32/package_esp32_index.json
   ```
2. 工具 → 开发板 → 开发板管理器 → 搜索 `esp32` → 安装 `esp32 by Espressif Systems`

### 7.3 安装 OLED 库
1. 工具 → 管理库 → 搜索并安装：
   - `Adafruit SSD1306`
   - `Adafruit GFX Library`

### 7.4 烧录
1. 用 USB 线连接 ESP32 到电脑
2. 工具 → 开发板 → 选择 `ESP32 Dev Module`
3. 工具 → 端口 → 选择对应的 COM 口
4. 打开 `firmware/firmware.ino`
5. 点击上传按钮（→ 箭头）
6. 等待烧录完成

## 第八步：安装 PC 端软件

### 8.1 安装 Python
1. 下载 Python 3.10+: https://www.python.org/downloads/
2. 安装时 **勾选 "Add Python to PATH"**

### 8.2 安装依赖
```bash
cd pc_agent
pip install -r requirements.txt
```

### 8.3 运行
```bash
python main.py
```

## 完成！

插上 USB，运行软件，你的 AI 网络安全管家就开始工作了 🎉
