# 🛒 淘宝零件清单 —— AI网络安全管家

## 方案概述

本设备是一个桌面微型安全监控终端，通过 USB 连接电脑，实时显示：
- 🤖 AI 助手状态（空闲/工作中/告警）
- 🔒 电脑安全等级（安全/警告/危险）
- 🌐 网络威胁实时数量
- 🛡️ 防火墙/杀毒软件状态
- 📊 异常进程/连接数
